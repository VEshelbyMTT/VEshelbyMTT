# Victoria Eshelby

I like data work where something does not add up, takes too long, or depends on one person to keep it alive, and I get to be the one who fixes it.

I currently work on analytics engineering for Mojang Studios and teach data and AI at Microsoft. Most of that work cannot live in a public repository, so this profile contains the things I can share honestly: teaching demos, learning projects, worked examples, and notes from problems I have tried to solve.

## Start here

- [Data portfolio](https://veshelbymtt.github.io/data-portfolio/) contains short accounts of my work in telemetry, data science, technical training, and research.
- [Today AI Learned](https://veshelbymtt.github.io/today-ai-learned/) is where I write down what happened when I used AI on real work, including the awkward parts and the decisions I kept for myself.
- [Demos](https://github.com/VEshelbyMTT/Demos) contains material from data, AI, analytics, and Databricks teaching.

My day-to-day tools include Python, SQL, PySpark, Databricks, Microsoft Fabric, and Azure. The tools change. The standard does not: somebody else should be able to understand and use what I build without me in the room, unless they want me there.
